## 零、先回答一个前提问题：「Nature 级」到底指什么

这个词极易流于口号。把它操作化为 **7 条可判定准则**，每条都要能回答「通过 / 不通过」：

| # | 准则 | 判定方式 |
|---|---|---|
| **N1** | **结论是机制而非数字**：给出可迁移的条件性规律，而非某个城市的容量值 | 主论点是「若…则…」形式的条件句，且有跨参数空间的稳定性证据 |
| **N2** | **关键量有外部锚点**：模型输出的每个关键强度/效率/阈值，都能对上已发表数值 | 产出「外部校验表」，逐项标明模型值 / 文献值 / 偏差 / 是否落在区间 |
| **N3** | **不确定性来自多条路径而非单次抽样**：报告分布、删失、收敛、跨境宽 across scenarios | 至少一个估计量的抽样达到收敛；报告 5–95% 与尾部 |
| **N4** | **参数空间被观测包络约束**：不是任意取值，而是落在真实技术/政策范围内 | 产出「参数包络表」，每个参数有来源 DOI；越界参数必有说明 |
| **N5** | **与社会或政策相关**：结论要能被决策者使用 | 至少一个结论以可检验的政策阈值表述（如 EU WUE 分级、电网接入条件） |
| **N6** | **方法透明可复现**：代码、环境、数据、命令可让第三方重跑出同样结果 | 环境锁定 + 产物哈希 + 第三方可执行的命令清单 |
| **N7** | **对既有文献有明确增量**，且能用一句话说清 | 相对 A1–A6 六篇已核实文献的差异性陈述 |

## 一、我们目前离这 7 条有多远（诚实自评）

| 准则 | 状态 | 说明 |
|---|---|---|
| N1 机制而非数字 | 🟡 **接近达成** | 主论点已是条件句形式，瓶颈迁移机制有反事实证据；但仅两个端点，泛化性弱 |
| N2 外部锚点 | 🔴 **本轮才发现严重不足** | PUE 与场地 WUE 落在真实区间✅；但**源端间接水低 91–96%，构成/结构倒置**（见下），此前无人发现 |
| N3 多路径不确定性 | 🟡 部分 | 有 20 条序列 + 精确二项 + 删失；但**序列来自同一合成生成器**（`hydrology_validation=NONE`），且 CO 抽样未收敛 |
| N4 参数包络约束 | 🔴 **未达成** | 多数参数是 assumption/scenario-tuned，无外部来源；EWIF 是典型例子（0.4/0.18 无出处） |
| N5 政策/社会相关 | 🟡 部分 | 有四类 estimand 之分，但政策阈值仍是内部自设；**现已找到真实外部阈值（EU 分级、西班牙电网接入条件）** |
| N6 可复现 | 🟡 部分 | 代码已 git 化、`REPRODUCTION_MANIFEST.md` 已生成；缺环境锁定与 charts 清单 |
| N7 文献增量 | 🟡 有候选陈述 | 「把 AI 作为需求扰动引入城市水系统的约束迁移」；但**必须做正式系统综述才能主张** |

**结论：限制我们的不是「没有 Nature 级想法」，而是 N2 与 N4 —— 模型还没被用来对外部世界做过任何诚实比对。而这两条恰好是现在就能补的，不需要城市实测数据。**

## 二、★ 核心战略转向

> **不能率定一座城市，但可以把参数空间钉死在真实观测的包络里。**

这是本轮最重要的判断，也是整份计划的支点。

- 上一轮我们卡在「没有真实数据 → 所有数字都是任意的 → 不能声称现实承载」。
- 但发表门槛其实不需要「某城市精确值」，而是「**结论在已观测的技术—政策包络内是否成立**」。
- 具体做法：把每个关键参数与每种政策阈值都换成**有 DOI 的可查数值/区间**，我们的数字就从「任意合成值」升级为「**在观测包络内的机制探索**」。后者是可发表的定位。

配套的一句话 Allerform（写作时统一口径）：

> 「本研究不估计任何具体城市可承载的 AI 容量；我们在**已观测的技术与政策包络内**做参数空间设计，检验关于约束迁移与干预有效性的**条件性规律**。」

## 三、任务分解

### T0（紧急，本周内）｜修复源端间接水因子 EWIF 🔴

**为什么最优先**：它污染所有与「AI 总水足迹」「水—能—碳权衡」有关的结论，且会使 N2/N4 直接判不通过。

| 项 | 内容 |
|---|---|
| 现状 | `examples/cawcc_r2/{ha,co}/project.json`：`offsite_electricity_water_intensity_l_kwh` = **0.4 / 0.18**；来源不清 |
| 外部区间 | 已核实：Green Grid WP#35 引 NREL 美国均值 **1.8**；LBNL 2024 **4.52**（且现实结构为间接 ≫ 直接，约 800 vs 660 亿升） |
| 修复后影响（线性因子，**可精确预估**，无需试错） | HA 间接占比 **17.6% → 49.1%（EWIF 1.8）/ 70.8%（4.52）**；CO **9.1% → 50.0% / 71.5%** |
| 副产物（关键） | EWIF 恢复后，Green Grid 记载的「改干冷却省现场水却抬高流域总耗水」权衡**应能出现**。若仍未出现，说明另有结构性缺失，那是新发现，须如实记录 |
| 验收标准 | ① 该参数写入已核实来源 DOI；② 以 `0.18 / 1.8 / 4.52` 三档做敏感性，报告结论对 EWIF 的敏感度；③ 重跑 `intervention_water_energy_carbon.csv` 与 `claim_register_R5.csv`；④ 若 M2/R5 之外任何结论数值改变，同步更新全部下游文档 |

> ⚠️ 诚实边界：0.18 并非一定错误（风光为主电网确实可以很低）。修复的正当表述是「**补上与文献对应的出处，并在三档情景下报告敏感度**」，而不是「把它改成某个值」。

### T1｜参数包络锚定（对应 N4）

- **T1.1** 产出 `parameter_envelope_R6.csv`：把全部 29 个现有参数逐项标注——取值范围、实测/文献/情景反算来源、**DOI 或政策文号**、判定 `IN_ENVELOPE` / `OUTSIDE` / `UNANCHORED`。
  - *验收*：越界与无出处参数各 ≤ 20%，且每一项都有《为什么保留》的书面理由。
- **T1.2** 补上**剩余两项阻断性文献缺口**（`文献基准矩阵_R6.md` 第五节）：
  - 城市**库容可靠性准则**（hedging rule / yield–reliability / 供水保证率）——目前完全无外部基准，直接卡住 estimand E3/E4 的表述合法性；
  - **可用气候集合产品**——现说明理由为何 Ganann 2023 只能作「为何需要多模型」的论据，不能当集合用；需专项检索可直接复用的产品（并评估是否涉及数据许可）。
- **T1.3** 端点与真实世界的对应关系：不引入数据，只在文中建立**定性类比**（HA ↔ Xiao 2025 所指 Nevada/Arizona 型缺水集群；CO ↔ New York / Midwest windbelt 型），并明确标注「类比为说明性，不作校准」。

### T3｜政策 estimand 的外部化（对应 N5）

现状：我们的「政策合规阈值」（E2）是内部自设，审稿人会问「这个阈值哪来的」。现在有了真实答案：

- 引入 **EU WUE 分级（A ≤0.10 … G >1.00）** 作为可直接引用的合规阈值；
- 引入**西班牙样式的「PUE/WUE 门槛 ↔ 电网接入」耦合**，正好把我们长期悬而未决的**电网语义（园区专线 vs 城市节点）**问题拿到真实政策语境下讨论，而不必依赖无法获得的节点数据。

*验收*：E2 不再由我们自设，而是至少一个真实颁布/草拟的阈值 + 一组情景边界。

---

### T4｜把先验换成锚定先验并重跑不确定性（对应 N3）

- **T4.1** 概率抽样的 3 项 AI 参数先验由「假设」改为「**锚定到 T1.1 的观测区间**」；重跑并复核 HA 的 `CONVERGED_PARTIAL` 与 CO 的 `INSUFFICIENT_BATCHES` 是否改善。
  - *验收*：CO 至少增加到能给出可报告的分布；若仍不足，如实写「条件于现有批次」并给出所需批次数的估算。
- **T4.2** 20 条序列保留但**标明其角色**：它检验的是「同一驱动规则下的采样稳定性」，不构成水文不确定性表征。若要后者，须接入 T1.2 检索到的集合产品——**先把它记为阻断项，不要含糊。**

### T5｜★ 机制泛化检验（对应 N1，**本轮通往 Nature 的核心动作**）

现状的最大软肋：**只有两个端点**。两个点没法支撑「规律」，最多支撑「对比」。而 N1 要求的是可迁移规律。

**做法**：在 T1.1 锚定的参数包络内做**空间填充设计**（如 Latin hypercube，30–60 组设计点），检验核心假设 H-M2：

> 「端点水源侧余量结构」是否能预测「哪类干预会有效」？

- 若该预测关系在包络内**稳定成立** → 得到一个真正的机制规律，这是 N1 的通过条件，也是相对 A1–A6 的明确增量。
- 若只在部分地区成立 → 报告成立的条件域（**阴性结果同样是 Nature 级产出**），并据此收缩主张。

*验收*：报告预测准确率 / 一致性频率；给出「余量结构 → 干预有效性」的判据与其适用范围。**禁止只凭两个端点下普遍结论。**

## 五、仍然不可跨越的边界（不可含糊）

1. **不得声称任何具体城市或城市类型的容量上界**——即使完成了 T5。我们能说的是「给定参数结构下的条件规律」。
2. **不得把 20 条合成序列包装成水文不确定性**——它始终是同一驱动规则的抽样，`hydrology_validation = NONE` 标签必须跟随。
3. **不得在系统综述完成前主张新颖性**——当前的说法只能作为内部假设。
4. **不得删除 CO 的同量级阴性结果**——它是已检验的边界条件。

## 六、一句话结论

本项目距离 Nature 级的差距，主要不在想法而在**外部诚实比对**。本轮已经证明这条路走得通：仅用一次与 LBNL / Green Grid 的数值比对，就发现了一个此前无人察觉的**数量级级偏差**，并由此解释了为何我们检不出文献明确记载的水—碳权衡。**继续做下去，比换城市数据更划算。**
