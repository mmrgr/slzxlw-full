## 当前研究在做什么

当前 B0 稿研究：**再生水替代比例如何通过冷却塔水质约束改变 AI 数据中心扩张时城市水系统的瓶颈位置。** 当混合补水中的盐分升高，冷却塔可接受的浓缩倍数可能下降，因而增加总补水需求。稿件给出临界替代率：

\[
r^{*}=\frac{L/\mathrm{CoC}_{d}-C_{p}}{C_{r}-C_{p}}
\]

其中，$L$ 为循环水水质限值，$\mathrm{CoC}_{d}$ 为设计浓缩倍数，$C_p$ 与 $C_r$ 分别为自来水和再生水的相应组分浓度。模型结果表明，水质惩罚只有在替代率越过阈值、且首个失效约束位于水量侧时，才会改变承载容量。

当前稿件用两个**合成参数端点**做城市水代谢模拟。$r^*=0.5532$ 是给定参数下的模型结果，不是实测城市的通用阈值；参数网格中该值会大幅变化。稿件已有 320 组全因子敏感性结果、1024 次参数抽样、多组分阈值与压力情景。100 MW 容量差是确定性情景差值，参数抽样带宽约 ±150 MW，不能表述为已由观测分辨出的效应。

**证据边界：**目前结果用于展示机制，不是任何真实城市的承载容量预测。主稿使用的 legacy 体积路径与动态溶质路径方向一致、效应量不同；动态路径下容量差约减半。外部冷却塔和水质资料已收集，但候选数据不等同于当前稿件的设施级独立验证样本。

```powershell

python .\figs\_gate_check_b0.py
```

## 版本与数据口径

- 根目录 `00_项目说明.md`、`00_项目文件总览.md` 和旧 README 编于 2026-09/10 月，描述的是较早的 R2/R3 或 A16 工作线，不是 B0 最新稿状态。
- `A40_投稿包/`、`A41_全包审计/`、`A43_投稿声明/`、`A45_工程治理规划/` 是早期 A16 投稿链。它们的复现清单、门禁结论和占位符只对其当时所审的文件集有效。
- `research_2026` 侧重 AI-UWM 引擎的 G0–G8 验证门禁；B0 侧重当前论文论证、分析图件和投稿稿件。二者有数据与代码联系，但状态不可互换。
- R2 导出说明所列的城市梯度与水文数据包括合成参数。引用数值时需同时给出来源、模拟时段、容量口径、求解路径和适用边界。
- 项目尚未在本目录确认统一的代码/数据许可。引用外部数据时遵守各自来源许可；不要把外部数据 DOI 当成本项目 B0 分析代码的版本 DOI。
