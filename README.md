## 这是什么

本项目回答一个具体问题：**一座城市引入 AI 数据中心的再生水冷却后，城市自来水取水量是升还是降？由什么决定？能否在干预前预测？**

核心不是"做一个模型"，而是**把结果建立在可核查的账本上**：

- **三本账分立**：申请水量（requested）、交付水量（delivered）、取水量（abstracted）在 68 个全引擎情景中**互不相等**（0/68 一致），证明单一水量核算不成立。
- **精确恒等式**：`dS_pot = C − F`（C = 既有用户被挤占后须补回的取水，F = 设施不再取的自来水），在 839 个求解可靠情景中残差 4.37e−11 ML（相对 3.55e−16，机器精度）。
- **零例外充分条件**：`q > 0`（q 为水质可行浓缩倍数判据）⇒ 城市受益，**263/263 无反例**。
- **部分识别**：committed 分支的现实占比**不可识别**（可证界 [0%, 100%]），我们如实报告边界而非给出点估计。

## 主要结论

| 结论 | 强度 |
|---|---|
| 三本账互不相等（0/68）+ 精确恒等式 | 极强 |
| `q > 0` ⇒ 城市受益，263/263 零例外 | 极强 |
| 组成调制符号（**限定 volume-only 口径**） | 强 |
| 外部锚定（10,826 WWTP / 141 项目 / 597 部署 / 31 城） | 强 |
| 折外候选判据（中位 +0.092，2/4 折） | 中 |

**诚实边界**（不做超出证据的声称）：无需求侧观测；机制归属未定（volume-only 求解路径的内部矛盾已在 SI S21 完整披露）；预测器未验证。**目标期刊定位：ES&T / Water Research。**
