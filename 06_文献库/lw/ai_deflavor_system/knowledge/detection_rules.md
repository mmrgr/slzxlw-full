# AI检测规则手册 — Detection Rules Manual

> **本文件汇总了主流AI检测工具的具体检测规则和绕过策略。** 检测模拟员在模拟检测时参考本文件，各Agent在修改文本时也参考本文件确保修改方向正确。

---

## 一、检测工具工作原理详解

### 1. GPTZero [$TRAE_REF](https://m.thepaper.cn/detail/26573330)

**检测逻辑**：
- 逐句计算困惑度（Perplexity）：用语言模型预测每个词的概率，概率越高→困惑度越低→越像AI
- 逐段计算突发性（Burstiness）：分析句子长度和复杂度的变化幅度
- 综合评分：低困惑度+低突发性 = 高AI概率

**绕过策略**：
- 提高困惑度：使用不常见的词汇、意外转折、跳跃性表达
- 提高突发性：大幅变化句子长度（一个3字短句接一个50字长句）、混用简单句和复杂句

### 2. Turnitin AI Detection [$TRAE_REF](https://blog.csdn.net/yweng18/article/details/161288940)

**检测逻辑**：
- 基于n-gram统计模型：分析词组组合的统计特征
- 训练数据痕迹匹配：与已知AI生成文本库比对
- 句式模式识别：检测AI偏好的句式结构
- 声称在受控实验中98%准确率

**绕过策略**：
- 打破n-gram模式：使用非常规的词语组合
- 引入人类写作痕迹：个人经历、口语化表达、不完美语法
- 改变句式模式：避免AI偏好的"主语+谓语+宾语+状语"标准结构

### 3. 知网AIGC检测 [$TRAE_REF](https://blog.csdn.net/aigccleaner/article/details/150852226)

**检测逻辑**：
- 训练数据痕迹：匹配AI模型的输出特征库
- 统计特征分析：句式均匀度、词汇分布、标点模式
- 语义重复检测：即使换词，语义高度重复也会被标记
- 中文特定模式：检测中文AI的固定句式和过渡词

**绕过策略**：
- 消除固定句式：替换所有AI高频过渡词
- 引入语义多样性：不是简单换词，而是改变表达角度
- 加入中文特有的人类写作特征：成语、俗语、口语化插入语

### 4. 维普AIGC检测 [$TRAE_REF](https://blog.csdn.net/aigccleaner/article/details/158070158)

**检测逻辑**：
- 句式模式识别：对并列句式、过渡词密集特别敏感
- 结构工整度检测：段落结构过于工整会被标记
- 词汇频率分析：AI高频词的密度检测

**绕过策略**：
- 打散段落结构：故意制造不对称
- 减少过渡词密度：每200字不超过1个过渡词
- 使用非标准句式：倒装、省略、碎片化表达

### 5. 腾讯朱雀 [$TRAE_REF](http://m.toutiao.com/group/7539203938965553664/)

**检测逻辑**：
- 千亿参数多模态模型：不仅看文本，还能检测图像
- 深度语义理解：不是简单模式匹配，而是理解文本深层特征
- 跨语言检测：中英文混合文本也能检测

**绕过策略**：
- 需要更深层次的人性化：表面修改不够，需要改变文本的"思维模式"
- 引入真正的人类思维痕迹：矛盾、犹豫、自我纠正
- 增加文本的"不可预测性"：在语义层面增加意外性

## 二、检测维度与评分标准

检测模拟员在模拟检测时，按以下维度评分（每项1-10分，1=高度人类特征，10=高度AI特征）：

| 维度 | 检测内容 | 评分标准 |
|------|----------|----------|
| **困惑度** | 词汇可预测性 | 1=大量罕见词汇和意外表达；10=词汇高度可预测 |
| **突发性** | 句子长度/结构变化 | 1=长短句大幅交错；10=句子长度均匀 |
| **词汇模式** | AI高频词密度 | 1=无AI标记词；10=AI标记词密集 |
| **结构模式** | 段落和论证结构 | 1=结构自然多变；10=三明治/三段式结构 |
| **逻辑模式** | 逻辑链平滑度 | 1=有矛盾/跳跃/反例；10=逻辑过于完美 |
| **情感模式** | 个人化程度 | 1=丰富的个人视角和感官细节；10=全程客观平铺 |
| **标点模式** | 标点使用规范性 | 1=有个性化标点使用；10=标点完全规范 |

**综合评分**：
- 7项平均分 ≤ 3.0：大概率通过检测（AI率 < 10%）
- 7项平均分 3.0-5.0：有风险（AI率 10%-30%）
- 7项平均分 > 5.0：高风险（AI率 > 30%）

## 三、各文体的检测阈值

| 文体 | 目标AI率 | 重点检测维度 | 允许的AI特征 |
|------|----------|-------------|-------------|
| **学术论文** | < 15% | 词汇模式、逻辑模式 | 适度结构化表达、被动语态（方法部分） |
| **小说/创意写作** | < 5% | 情感模式、突发性 | 极少，需要最大化人性化 |
| **新闻文章** | < 10% | 结构模式、情感模式 | 基本新闻结构（倒金字塔） |
| **博客/自媒体** | < 10% | 词汇模式、结构模式 | 适度结构化 |
| **公文/报告** | < 20% | 词汇模式 | 较多结构化表达可接受 |

## 四、检测规避的核心原则

### 原则1: 提高困惑度（不可预测性）

```
AI原文：人工智能正在改变教育领域，为学生提供了更多学习机会。
提高困惑度：教室里那台总死机的旧电脑换了AI系统后，后排睡觉的男生居然开始举手了——这大概就是技术渗透教育的一个微观切面。
```

技巧：
- 用具体场景替代抽象表述
- 用意外转折替代平铺直叙
- 用罕见词汇替代高频词汇
- 用比喻/类比替代直接陈述

### 原则2: 提高突发性（变化度）

```
AI原文（低突发性）：
人工智能在教育领域的应用日益广泛。首先，它可以实现个性化教学。其次，它能够提供即时反馈。最后，它帮助教师减轻工作负担。

人类写法（高突发性）：
AI进教室了。说实话，效果出乎意料——不是那种宏大的"改变教育"，而是很具体的变化：三班的数学老师不用再熬夜批作业了，学生做的错题系统自动归类，连"哪道题错最多"这种事都不用人统计了。当然，也有麻烦。有学生开始用AI写作文，写得还挺好，老师头疼得很。
```

技巧：
- 长短句交错（一个3字短句接一个50字长句）
- 偶尔用碎片化句子
- 段落长度大幅变化
- 偶尔插入括号补充、反问、感叹

### 原则3: 消除词汇模式

```
需要消除的高频词 → 替代策略：
此外 → 删掉，用语义衔接；或"话说回来""换个角度"
然而 → "问题在于""但话说回来""不过"
综上所述 → 删掉，直接给结论；或"这至少说明"
值得注意的是 → 删掉，直接说；或"有意思的是"
研究表明 → "Smith等（2023）发现"（加具体来源）
日益增长 → "从2018年到2023年翻了三倍"（具体数据）
```

### 原则4: 打破结构模式

- 打散三明治结构：不从"随着...的发展"开头，从一个具体案例或问题切入
- 打破三段式：不用"（1）（2）（3）"，用自然段落过渡
- 制造不对称：让某个段落特别长，某个段落只有一句话
- 插入"跑题"：在论述中偶尔插入看似无关但实际相关的个人感受

### 原则5: 增加逻辑复杂性

- 引入矛盾："虽然X，但Y"——人类写作常有矛盾
- 承认不确定："这一点目前还没有定论"
- 提供反例："但也有例外..."
- 添加限定条件："在...的情况下，这一结论成立"
- 质疑自己的论点："当然，这个说法可能有争议"

### 原则6: 注入情感和个人化

- 加入个人经历："根据我的经验..."
- 加入感官细节：视觉、听觉、触觉
- 加入时间锚点："2023年春天""上周"
- 加入情感反应："说实话，这个结果让我意外"
- 加入口语化表达："说白了""坦白讲""怎么说呢"

## 五、检测流程模拟

检测模拟员在执行检测时，按以下流程：

```
Step 1: 全文扫描
  - 统计AI高频词出现频率
  - 计算句子长度标准差
  - 检测结构模式（三明治/三段式）
  - 识别标点使用模式

Step 2: 逐段分析
  - 每段困惑度估算（词汇可预测性）
  - 每段突发性估算（句子变化度）
  - 段间过渡模式分析

Step 3: 逐句标记
  - 标记高AI概率句子（低困惑度+低突发性）
  - 标记AI高频词出现位置
  - 标记AI结构模式出现位置

Step 4: 综合评分
  - 7个维度各打1-10分
  - 计算平均分
  - 估算AI率

Step 5: 生成报告
  - 整体AI率估算
  - 高风险段落列表
  - 高风险句子列表
  - 具体问题清单
  - 修改建议
```
