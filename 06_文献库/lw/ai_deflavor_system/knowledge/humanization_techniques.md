# 人性化技术手册 — Humanization Techniques Manual

> **本文件是去AI味系统的核心技术手册。** 汇总了从网络研究中收集的所有有效降低AI痕迹的方法，以及每种方法的具体操作示例。各Agent在修改文本时必须参考本文件。

---

## 一、人性化技术总览

```
输入文本（AI味浓）
    │
    ├─→ T1: 结构重组（打破AI结构模式）
    ├─→ T2: 词汇替换（消除AI标记词）
    ├─→ T3: 句式变化（提高突发性）
    ├─→ T4: 逻辑复杂化（打破完美逻辑链）
    ├─→ T5: 情感注入（增加个人化特征）
    ├─→ T6: 数据具体化（消除假数据）
    ├─→ T7: 文体适配（按文体调整策略）
    │
    ▼
输出文本（AI味低）
```

## 二、七大技术详解

### T1: 结构重组

**目标**：打破AI的结构性模式，制造"自然的不完美"。

| 技术 | 操作方法 | 示例 |
|------|----------|------|
| **案例先行法** | 不从宏观背景开头，从一个具体案例切入 | AI: "随着城市化进程加快..." → 人类: "去年冬天，我在XX河岸边散步时，看到水面漂着一层薄膜..." |
| **乱序写作法** | 先写案例再补理论，故意打乱"总-分-总"结构 | 把结论放到中间，开头用现象，结尾用反思 |
| **不对称段落** | 让某个段落特别长（200字+），某个段落只有一句话 | 在长段论述后插入一行："这就是问题所在。" |
| **插入跑题** | 在论述中插入看似无关但实际相关的个人感受 | 在数据分析段落后插入："看到这组数据时，我第一反应是不信。" |
| **问题开篇法** | 用一个问题开头，而不是陈述 | AI: "XX是重要的环境问题" → "为什么XX河流域的鱼类在过去五年减少了60%？" |
| **结尾留白** | 不做完美总结，用开放性结尾或反思替代 | AI: "综上所述，..." → "或许，真正的答案不在于技术本身，而在于我们如何定义'解决'。" |

### T2: 词汇替换

**目标**：消除AI高频标记词，用自然表达替代。

**中文替换表**（高频AI词 → 自然替代）：

| AI词汇 | 自然替代（选一） |
|--------|-----------------|
| 此外 | 话说回来 / 换个角度看 / 还有一层 / 另外提一句 |
| 与此同时 | 说白了就是 / 换句话说 / 顺带一提 |
| 另一方面 | 反过来看 / 但站在对立面想 / 不过话说回来 |
| 然而 | 问题在于 / 但 / 不过 / 说实在的 |
| 值得注意的是 | 有意思的是 / 容易被忽略的是 / 这里有个细节 |
| 必须强调的是 | 这里要划重点 / 千万别忽略 / 关键就在这 |
| 综上所述 | 这至少说明 / 一个合理的推断是 / 回过头看 |
| 总而言之 | 说到底 / 归根结底 / 一句话概括 |
| 由此可见 | 照这个逻辑 / 顺着这个思路 |
| 研究表明 | Smith等（2023）发现 / 环境部的报告显示 |
| 日益增长 | 从2018年到2023年翻了两番 / 每年增长15% |
| 不可或缺 | 没它就运转不了 / 核心环节 |
| 至关重要 | 算是命门 / 掉了链子就全完了 |
| 赋能 | 给了...能力 / 让...能做... |
| 重构 | 推翻重来 / 重新搭了一遍 |

**英文替换表**：

| AI词汇 | 自然替代 |
|--------|---------|
| Furthermore / Moreover | What's more / On top of that / And there's another layer |
| Additionally | Plus / Also / And |
| However / Nevertheless | But / That said / Still |
| It is worth noting that | Worth mentioning / Here's the thing |
| It is important to note | Keep in mind / The key point is |
| plays a crucial role | matters a lot / is central to |
| sheds light on | helps explain / clarifies |
| In today's world | Right now / These days |
| increasingly | more and more / year by year |
| significantly | in a big way / by a wide margin |

### T3: 句式变化

**目标**：提高突发性（Burstiness），让句子长度和结构大幅变化。

| 技术 | 操作方法 | 示例 |
|------|----------|------|
| **长短交错** | 一个3-5字短句接一个40-60字长句 | "没用。至少在XX流域的实测数据里，那个模型预测的偏差超过了30%，这意味着..." |
| **碎片化句子** | 偶尔用不完整句子 | "但问题远没这么简单。" "真的吗？" |
| **倒装句** | 调换句子成分顺序 | "罕见的是，这一现象在热带地区也有报道。" |
| **反问句** | 用反问替代陈述 | AI: "这说明该方法有效。" → "这还能说明别的吗？" |
| **括号插入** | 用括号补充说明或吐槽 | "该方法的准确率达到85%（当然，这是在理想条件下）。" |
| **破折号转折** | 用破折号表示思维转折 | "数据显示效果显著——如果你愿意相信那个样本量只有30的研究的话。" |
| **省略号停顿** | 用省略号制造思考感 | "这个结论...怎么说呢，有点 premature。" |

### T4: 逻辑复杂化

**目标**：打破AI过于完美的逻辑链，引入人类思维的复杂性。

| 技术 | 操作方法 | 示例 |
|------|----------|------|
| **引入矛盾** | "虽然X，但Y" | "虽然数据支持这一假说，但在XX站的重复实验中，结果恰恰相反。" |
| **承认不确定** | 明确表达不确定 | "这一点目前还没有定论，现有证据不足以做出判断。" |
| **提供反例** | "但也有例外" | "总体趋势如此。不过，XX地区是个例外——那里的浓度反而下降了。" |
| **添加限定条件** | 明确适用范围 | "这一结论在温带地区成立，但能否推广到热带还存疑。" |
| **自我质疑** | 质疑自己的论点 | "当然，这个说法可能有争议。反对者会指出..." |
| **因果变相关** | 不强行因果 | AI: "由于X，导致Y" → "X和Y之间存在关联，但谁是因谁是果——或者是否有第三方因素——目前不清楚。" |
| **多角度分析** | 从不同角度讨论同一问题 | "从生态学角度看...但从经济学角度看...而从政策层面..." |

### T5: 情感注入

**目标**：增加文本的个人化特征和情感温度。

| 技术 | 操作方法 | 示例 |
|------|----------|------|
| **个人经历** | 插入"根据我的经验""我注意到" | "根据我在三个采样点的实地观察，..." |
| **感官细节** | 加入视觉/听觉/触觉 | "水样浑浊发黄，隔着采样瓶能闻到一股铁锈味。" |
| **时间锚点** | 加入具体时间 | "2023年春季采样期间""上周组会上" |
| **情感反应** | 表达惊讶/困惑/兴奋 | "说实话，这个结果让我意外。" |
| **口语化表达** | 加入"说白了""坦白讲""怎么说呢" | "说白了，现有模型根本没考虑到季节波动。" |
| **自嘲/幽默** | 偶尔自嘲或用反讽 | "当然，我的模型完美——如果你忽略那30%的偏差的话。" |
| **主观判断** | 表达个人观点 | "我认为这个方向被严重低估了。" |

### T6: 数据具体化

**目标**：消除AI的假数据和模糊数据，用具体来源替代。

| AI写法 | 人类写法 |
|--------|---------|
| "据统计78%的用户表示..." | "中国互联网络信息中心2023年报告显示，76.8%的受访用户..." |
| "研究表明..." | "Wang等（2023, Nature Water）的研究发现..." |
| "大量数据证明..." | "三项独立研究（Smith 2021; Chen 2022; 李等 2023）均指出..." |
| "显著提升" | "提升了34.2%（p < 0.01，n=150）" |
| "广泛认可" | "被WHO指南和欧盟标准采纳" |

### T7: 文体适配

**学术论文特殊策略**：
- 方法部分可以保留结构化（检测工具对方法部分容忍度高）
- 文献综述改为"叙事式"而非"罗列式"
- 讨论部分是重点人性化对象
- 保留必要的学术规范（引用、数据准确性）

**小说/创意写作特殊策略**：
- 对话必须口语化，每个人都有独特的说话方式
- 描写要有感官细节，不能只有视觉
- 情感表达要有层次，不能直接说"他很伤心"
- 允许更多"不完美"（碎片化、意识流）

**新闻文章特殊策略**：
- 导语可以有结构，但正文要有现场感
- 引用要有具体来源（姓名、职务）
- 加入记者的观察细节

## 三、技术组合策略

不同AI味严重程度需要不同力度的处理：

### 轻度AI味（AI率 30-50%）
**策略**：T2(词汇替换) + T3(句式变化) + 局部T5(情感注入)
**工作量**：每1000字修改约15-20处
**目标**：AI率降到15%以下

### 中度AI味（AI率 50-70%）
**策略**：T1(结构重组) + T2(词汇替换) + T3(句式变化) + T4(逻辑复杂化) + T5(情感注入)
**工作量**：每1000字修改约25-35处
**目标**：AI率降到10%以下

### 重度AI味（AI率 70%+）
**策略**：全部7种技术 + 深度重写
**工作量**：每1000字修改约40+处，部分段落需要重写
**目标**：AI率降到5%以下

## 四、修改质量检查清单

每次修改后，质量把控师检查：

```
□ 原意是否保留？（不能因为去AI味而改变原文含义）
□ 逻辑是否通顺？（不能因为打乱结构而导致逻辑断裂）
□ 语言是否自然？（不能为了去AI味而变得刻意）
□ 学术规范是否保留？（引用、数据不能被修改破坏）
□ 个人风格是否一致？（不能一段像论文，一段像博客）
□ 是否过度修改？（如果修改后反而不自然，需要回退）
□ 目标AI率是否达到？（检测模拟员重新检测）
```

## 五、常见错误

| 错误 | 后果 | 正确做法 |
|------|------|---------|
| 过度替换词汇 | 文章读起来像"翻译腔" | 只替换最明显的AI标记词 |
| 过度碎片化 | 文章支离破碎 | 碎片化句子不超过10% |
| 过度口语化 | 学术论文不像学术 | 根据文体调整口语化程度 |
| 强行加个人经历 | 显得做作 | 个人经历要自然融入 |
| 破坏数据准确性 | 学术不端 | 数据和引用绝对不能改 |
| 忽略文体差异 | 论文像小说 | 严格按照T7文体适配 |
