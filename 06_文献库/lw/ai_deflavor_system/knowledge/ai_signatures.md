# AI味特征知识库 — AI Signature Knowledge Base

> **本文件是去AI味系统的核心知识库。** 基于对主流AI检测工具（GPTZero、Turnitin、ZeroGPT、知网AIGC检测、维普、腾讯朱雀）的检测原理研究，以及对大量AI生成文本的特征分析，系统性地归纳了AI味的六大类特征。所有Agent在执行任务时必须参考本文件。

---

## 一、检测原理：两大核心指标

AI检测工具的核心逻辑基于两个统计指标 [$TRAE_REF](https://m.sohu.com/a/947036907_121972770/) [$TRAE_REF](https://blog.csdn.net/aigccleaner/article/details/150852226)：

### 1. 困惑度（Perplexity）
- **定义**：衡量文本的"不可预测性"。下一个词越难预测，困惑度越高。
- **AI表现**：AI生成的文本倾向于选择概率最高、最"安全"的词，导致困惑度低、文本"过于流畅"。
- **人类表现**：人类写作用词更不可预测，会使用罕见的表达、跳跃性的思维，困惑度高。
- **检测阈值**：GPTZero对低困惑度段落标记为AI生成 [$TRAE_REF](https://m.thepaper.cn/detail/26573330)。

### 2. 突发性（Burstiness）
- **定义**：衡量句子结构和长度的变化程度。
- **AI表现**：AI生成的句子长度均匀、结构一致，突发性低。
- **人类表现**：人类写作长短句交错、结构多变、偶尔出现碎片化句子，突发性高。
- **检测逻辑**：Turnitin和GPTZero都会检测句子长度的标准差，标准差小说明是AI [$TRAE_REF](http://www.paperbert.com/f/na-ge-ai-xie-bi-ye-lun-wen-hao-yong.html)。

### 检测工具矩阵

| 工具 | 主要指标 | 适用语言 | 特点 |
|------|----------|----------|------|
| GPTZero | Perplexity + Burstiness | 英文为主 | 句段级AI概率标注 |
| Turnitin AI | 统计特征 + n-gram | 英文为主 | 学术论文检测，声称98%准确率 |
| ZeroGPT | 文本分类模型 | 英文 | 简单快速但误判率较高 |
| 知网AIGC | 训练数据痕迹 + 统计特征 | 中文 | 中文论文最严格 |
| 维普AIGC | 句式模式 + 过渡词频率 | 中文 | 对结构工整度敏感 |
| 腾讯朱雀 | 千亿参数多模态模型 | 中英 | 文本+图像双通道 |

## 二、AI味的六大类特征

### 类别1: 结构性AI味

| 特征 | AI表现 | 检测权重 |
|------|--------|----------|
| **三明治结构** | "随着...的发展，...已成为重要课题。本文将从以下三个方面展开" | 高 |
| **三段式论证强迫症** | 无论什么主题都强行分三点："其优势主要体现在：（1）...（2）...（3）..." | 高 |
| **段落长度均匀** | 每段字数接近，没有特别长或特别短的段落 | 高（Burstiness低） |
| **总分总结构** | 开头概述→分述→结尾总结，过于工整 | 中 |
| **完美的逻辑递进** | 每段之间过渡平滑，没有跳跃 | 中 |
| **对称性排列** | 论点排列工整，每个论点篇幅相近 | 中 |

### 类别2: 词汇性AI味

**中文高频AI标记词** [$TRAE_REF](https://blog.csdn.net/aigccleaner/article/details/150056785) [$TRAE_REF](https://k.sina.cn/article_7880068741_1d5b04e8506801kky4.html)：

| 类型 | 高频AI词汇 | 替代方向 |
|------|-----------|----------|
| 并列连接词 | 此外、与此同时、另一方面、不仅如此、另外 | 用语义衔接替代，如"话说回来""换个角度看" |
| 转折连接词 | 然而需要注意的是、必须强调的是、值得注意的是 | 用自然转折，如"问题在于""但话说回来" |
| 总结连接词 | 综上所述、总而言之、由此可见、不难看出 | 用具体推论替代，如"这至少说明""一个合理的推断是" |
| 空话术语 | 赋能、重构、深度、生态、闭环、抓手、痛点 | 用具体描述替代 |
| 被动表达 | 研究表明、数据显示、可以得出、被认为是 | 主动语态+具体来源 |
| 模糊修饰 | 不可或缺、至关重要、举足轻重、日益增长 | 具体程度描述 |

**英文高频AI标记词**：
| 类型 | 高频AI词汇 |
|------|-----------|
| 过渡词 | Furthermore, Moreover, Additionally, Consequently, Nevertheless |
| 空洞表达 | It is worth noting that, It is important to note, In today's world |
| 学术套话 | plays a crucial role, sheds light on, paves the way for |
| 模糊修饰 | increasingly, significantly, notably, remarkably |
| 被动结构 | It has been shown that, It is widely recognized that |

### 类别3: 统计性AI味

| 指标 | AI表现 | 检测方法 |
|------|--------|----------|
| **句子长度方差** | 标准差小（句子长度均匀） | Burstiness检测 |
| **词汇多样性** | TTR（类型-Token比）偏低但均匀 | 词汇分布分析 |
| **n-gram重复** | 常见n-gram组合频率高 | n-gram模型匹配 |
| **困惑度分布** | 整体偏低且分布均匀 | 逐句困惑度计算 |
| **标点使用模式** | 标点使用过于规范，无个性化 | 标点序列分析 |
| **段落节奏** | 段落间过渡过于平滑 | 段落衔接分析 |

### 类别4: 逻辑性AI味

| 特征 | AI表现 | 示例 |
|------|--------|------|
| **虚构逻辑链** | 强行因果，两者可能只是相关 | "由于移动支付普及，老年人数字鸿沟扩大" |
| **过度平滑** | 逻辑链条过于完美，没有矛盾 | A→B→C→D，每步都顺滑 |
| **缺乏反证** | 只说支持论点的证据，不讨论反例 | 只列优势不提局限 |
| **伪深度** | 用学术黑话假装深刻 | "福柯的话语理论与网红经济呈现后现代的熵增效应" |
| **假数据** | "据统计78%的用户表示..."（无来源） | 人类会写"第三方白皮书显示该数值在65%-80%间浮动" |
| **过度概括** | 从个案直接跳到普遍结论 | "一个案例证明所有..." |

### 类别5: 情感性AI味

| 特征 | AI表现 | 人类对比 |
|------|--------|----------|
| **情绪刻度缺失** | "短视频成瘾可能引发注意力衰退" | "上周亲眼目睹表弟刷抖音3小时后，突然抬头问'现在几点了'时的茫然眼神" |
| **无个人视角** | 全程客观陈述，没有"我" | 人类会插入"根据我的经验""我注意到" |
| **无感官细节** | 纯抽象论述 | 人类会加入"摸着发烫的手机背板""隔着口罩闻到的消毒水味" |
| **无时间锚点** | 泛泛而谈，无具体时间 | 人类会写"2023年春季""上周组会" |
| **无幽默/自嘲** | 全程严肃 | 人类偶尔会自嘲或用反讽 |

### 类别6: 文体适应性AI味

| 文体 | AI味特殊表现 |
|------|-------------|
| **学术论文** | 过度使用被动语态、文献综述机械堆砌、讨论部分过度推断 |
| **小说/创意写作** | 人物对话千篇一律、描写过于"完美"、缺乏口语化、情感表达表面化 |
| **新闻文章** | 导语模式化、引用来源模糊、缺乏现场感 |
| **博客/自媒体** | 结构过于工整、缺乏个人风格、标题党但内容空洞 |

## 三、AI味检测清单

AI特征检测员在分析文本时，逐项检查以下清单：

```
结构检查：
□ 是否有三明治结构（"随着...的发展，...已成为..."）
□ 是否有三段式论证（"（1）...（2）...（3）..."）
□ 段落长度是否过于均匀（标准差 < 平均长度的20%）
□ 是否总分总结构过于工整
□ 论点排列是否过于对称

词汇检查：
□ "此外/与此同时/另一方面"每200字出现≥3次
□ "然而需要注意的是/必须强调的是/值得注意的是"出现
□ "综上所述/总而言之/由此可见"出现
□ "赋能/重构/深度/生态/闭环"等空话出现
□ "研究表明/数据显示"无具体来源
□ 英文：Furthermore/Moreover/Additionally高频出现

统计检查：
□ 句子长度标准差是否过小
□ 词汇分布是否过于均匀
□ 标点使用是否过于规范（无破折号、省略号等个性化标点）
□ 困惑度是否整体偏低

逻辑检查：
□ 是否有强行因果（相关当因果）
□ 逻辑是否过于平滑（无矛盾、无反例）
□ 数据是否有具体来源
□ 是否从个案直接跳到普遍结论

情感检查：
□ 是否有个人视角（"我""我们"的合理使用）
□ 是否有感官细节
□ 是否有时间锚点
□ 是否有情感波动（而非全程平铺）

文体检查：
□ 对话是否口语化（小说）
□ 文献综述是否机械堆砌（论文）
□ 是否有现场感（新闻）
□ 是否有个人风格（博客）
```

## 四、重要提醒

1. **不是所有特征都需要修改**：一篇文本可能只有3-4个AI味特征，不需要全部消除。检测员应标注每个特征的严重程度（高/中/低）。
2. **过度修改比AI味更有害**：如果修改后文本不通顺、逻辑混乱，比保留适度AI味更糟糕。质量把控师必须把关。
3. **不同文体的AI味阈值不同**：学术论文允许更多结构化表达；创意写作需要最大化人性化。
4. **检测工具在持续进化**：本知识库需要定期更新，记忆管家应记录新的AI味模式。
