## 1. 任务 A：完整物种水样上的城市级 $dS_{\rm pot}$

### 1.1 口径（严格沿用 WP2 §2，未修改）

$$dS_{\rm pot}=C-F=\bigl(r_{\rm inc}^{B_2}-r_{\rm inc}^{B_1}\bigr)-(M_0-M_1)-x_{\rm AI}$$

- $B_1$：有数据中心、**不用**再生水（`ai_target=0`）→ $M_0,\mathrm{CoC}_0$
- $B_2$：有数据中心、**使用**再生水（`ai_target=\varphi`）→ $M_1,\mathrm{CoC}_1,x_{\rm AI}$
- $C=\max(0,\,r_{\rm inc}^{B_2}-r_{\rm inc}^{B_1})$，$F=(M_0-M_1)+x_{\rm AI}$
- 符号约定：$dS_{\rm pot}>0$ = 城市净取水**上升（有害）**；$<0$ = 下降（有益）
- **未混入 $B_0\to B_1$**；未采用已撤回的 psi/Delta 口径。

水样化学**全部来自 `city_model.load_samples()`**，未自造任何数值。

### 1.2 扫描设计与门禁

| 项 | 取值 |
|---|---|
| 水样（主口径，仅完整物种） | IEUA RP-1 (2025, tertiary)、LADWP AWPF (2012, RO product) |
| 域 | `ha`, `co` |
| $\varphi$ | 0, 0.2, 0.4, 0.6, 0.8 |
| `pool_scale` | 1, 2, 3 |
| 面板 | `B_full`（5 物种引用档 GB/T 50050-2017） |
| 情景总数 $n_{\rm all}$ | **60** |
| **$n_{\rm eff}$** | **47** |
| 剔除数 | 13（12 = $\varphi=0$ 退化档；1 = `no_convergence`） |

**双层门禁**（均按 A26 语义表执行）：

| 门禁 | 通过数 |
|---|---|
| ① $B_2$ 支路 `status == converged_unique` | 47 / 60 |
| ② $B_1$ 支路单根且闭合（`root=1`，$|\text{closure\_residual}|\le10^{-9}$） | 60 / 60 |
| ③ 两支路 CoC 均不触引擎下限（$>1.000001$） | 60 / 60 |

剔除情景已逐条记录在 `wp4_summary.json → excluded_scenarios`（含域、水样、$\varphi$、`pool_scale`、原因），**未静默丢弃**。

### 1.3 恒等式残差（相对容差）

量级可达 $2.5\times10^4$ ML，故**绝对容差无意义**，一律用相对残差
$|{\rm pred}-{\rm obs}|/\max(|{\rm obs}|,10^{-30})$：

| 检验 | 最大相对残差 | 判定 |
|---|---:|---|
| (a) $dS = C - F$ | `0.000e+00` | ✅ PASS |
| (b) $dS = \max(0,\Delta r_{\rm inc}) - \Delta M - x_{\rm AI}$ | `0.000e+00` | ✅ PASS |
| (b′) 对照：**不截断** $\Delta r_{\rm inc}$ | `1.174e+00` | ❌ FAIL（证明 $\max(0,\cdot)$ 必要） |

> **(b′) 是一个实质性发现**：$r_{\rm inc}^{B_2}-r_{\rm inc}^{B_1}$ 在池被既有用户用尽时
> **恒等于 $-x_{\rm AI}$**（制度①，15 情景，$|\text{位移}+x_{\rm AI}|_{\max}=3.6\times10^{-12}$）。
> 若不作 $\max(0,\cdot)$ 截断而直接代入，$dS=-x_{\rm AI}-(M_0-M_1)-x_{\rm AI}$
> 会**重复扣减 $x_{\rm AI}$**（双计），残差达 117%。
> 这也解释了为何 A13c 原实现使用 $\max(0,\cdot)$ —— 该截断是**物理必需**，不是装饰。

三种位移制度（实测确认，`wp4_summary.json → displacement_identity`）：

| 制度 | 条件 | 情景数 | 带符号位移 |
|---|---|---:|---|
| ① 池在 $B_1$ 被既有用户用尽 | `inc_B1 ≥ pool` 且未饱和 | 15 | $=-x_{\rm AI}$ |
| ② $B_1$ 已使既有用户饱和 | `inc_B1 ≥ elig` | 0 | $=0$ |
| ③ 部分情形 | 其余 | 32 | 介于 $-x_{\rm AI}$ 与 0 之间 |

### 1.4 逐情景结果与 $q$ / $dS_{\rm pot}$ 符号

**汇总（$n_{\rm eff}=47$）**：

| 量 | 计数 |
|---|---:|
| $dS_{\rm pot}<0$（受益） | **47** |
| $dS_{\rm pot}=0$ | 0 |
| $dS_{\rm pot}>0$（有害） | **0** |
| $q>0$ | 23 |
| $q<0$ | 24 |

零值约定：$|dS_{\rm pot}|<10^{-6}$ ML 记为 0，不计入正负计数。

**按水样（$q$ 符号逐水样完全一致）**：

| 水样 | $n_{\rm eff}$ | 物种 | $\mathrm{CoC}_0$ | $\mathrm{CoC}_1$ 范围 | $q$ 范围 | $q$ 符号 | $dS$ 符号 |
|---|---:|---:|---|---:|---|---|---|
| IEUA RP-1 | 24 | 5（完整） | 3.500 | 2.653 – 3.355 | $-0.128$ – $-0.017$ | **恒负** | 全负 |
| LADWP AWPF | 23 | 5（完整） | 3.500 | 3.894 – 5.000 | $+0.040$ – $+0.120$ | **恒正** | 全负 |

**关键对照（$\varphi=0.6$，`pool_scale=1`）**——$q$ 与 $dS$ 方向相反：

| 域 | 水样 | $q$ | $M_0-M_1$ | $x_{\rm AI}$ | $F$ | $dS_{\rm pot}$ |
|---|---|---:|---:|---:|---:|---:|
| ha | IEUA（脏） | $-0.0439$ | $-1320.5$ | 8905.6 | 7585.1 | $-7585.1$ |
| ha | LADWP（净） | $+0.1069$ | $+2777.3$ | 8154.4 | 10931.7 | $-10931.7$ |
| co | IEUA（脏） | $-0.0395$ | $-1169.5$ | 7897.1 | 6727.5 | $-6727.5$ |
| co | LADWP（净） | $+0.0957$ | $+2481.3$ | 7285.9 | 9767.2 | $-9767.2$ |

**机制解读（本轮新发现，务必写入正文）**：
$F=(M_0-M_1)+x_{\rm AI}$ 中两项**反向运动**。LADWP 水更干净 ⇒ 允许更高 CoC ⇒
补水**更省**（$M_0-M_1>0$，这是 $q>0$ 的含义）；但同样因为 CoC 高、排污少，
**达到同一掺混比所需再生水量更少**（$x_{\rm AI}$ 8154 < 8906）。
后者（$x_{\rm AI}$ 项）量级更大且符号相反，故 $dS$ **更负**。
**全网格相关系数**：$\mathrm{corr}(q,dS)=-0.16$，而 $\mathrm{corr}(x_{\rm AI},dS)=-0.93$。
⇒ **驱动城市节水的是"取用了多少再生水"，而非"水质使补水省了多少"。**

### 1.5 H3 检验：$q>0$ 是否为城市受益的充分条件？

| 量 | 值 |
|---|---:|
| $n_{\rm eff}$ | 47 |
| $q>0$ 且 $dS<0$ | 23 |
| $q>0$ 而 $dS>0$（**反例**） | **0** |
| $q<0$ 且 $dS<0$ | 24 |
| 裁定 | **SUPPORTED（无充分性反例）** |

⚠ **但必须诚实标注其为"空洞通过"风险**：可靠子集内 $dS$ **全部为负**，
故"$q>0\Rightarrow$ 受益"**没有任何鉴别力**——它也同时满足
"$q<0\Rightarrow$ 受益"。该检验在此数据集上**不能区分**充分性。按门禁第 4/8 条，
建议正文报为 "$n_{\rm eff}=47$，反例 0，但检验因 $dS$ 无正例而**不具鉴别力**"，
不得表述为"H3 得到有力证实"。

## 2. 任务 B：「缺失物种按 0」的偏差方向与幅度

### 2.1 偏差机制

`city_model.quality_dict` 只挑出水样中**存在**的物种；面板 `B_full` 要求 5 个。
缺失物种浓度被当作 **0** ⇒ 该物种限值**永不触发** ⇒ 水样显得更"干净"
⇒ CoC 偏高、$q$ 偏正 ⇒ **系统性偏向"回用有益"**（与 A22 登记方向一致）。

填充区间**由权威表内完整物种水样（IEUA/LADWP）的观测导出**，非自造：

| 物种 | lo | mid | hi | 捐赠值 |
|---|---:|---:|---:|---|
| TDS | 22 | 232.5 | 443 | 443, 22 |
| chloride | 3.6 | 51.8 | 100 | 100, 3.6 |
| hardness | 1.024 | 75.23 | 149.4 | 149.4, 1.02 |
| alkalinity | 7.1 | 73.55 | 140 | 140, 7.1 |
| silica | 0.52 | 12.26 | 24 | 24, 0.52 |

> 这些是"其他真实水样的取值范围"，用于**界定偏差方向**，
> **不是**对缺测水样真实浓度的估计。

### 2.2 结果（$\varphi=0.6$，每处理 6 情景）

| 水样 | 处理 | $q$ 中位 | $dS$ 中位 (ML) | $q$ 符号 |
|---|---|---:|---:|---|
| Figshare RW（缺 alkalinity, silica） | A 按 0 | $-0.2051$ | $-11345$ | neg |
| | B 下界 | $-0.2051$ | $-11345$ | neg |
| | C 中位 | $-0.2051$ | $-11345$ | neg |
| | D 上界 | $-0.2051$ | $-11345$ | neg |
| | E 压力档（2×上界） | $-0.3285$ | $-6551$ | neg |
| **AI-UWM assumption**（缺 hardness, alkalinity, silica） | A 按 0 | $+0.1099$ | $-18296$ | **pos** |
| | B 下界 | $+0.1068$ | $-18296$ | pos |
| | C 中位 | $+0.0570$ | $-17376$ | pos |
| | **D 上界** | $-0.0822$ | $-14677$ | **neg ← 翻转** |
| | **E 压力档** | $-0.3285$ | $-6551$ | **neg ← 翻转** |
| Figshare BW（苦咸水对照） | 全部 | $-0.8509$ | $+127426$ | neg |

### 2.3 裁定

1. **AI-UWM assumption（仅 2 物种）：$q$ 的符号会随缺测填充水平翻转**
   （$+0.110\to-0.082$）。⇒ 其"再生水更干净"的结论是**"缺失按 0"的人为产物**，
   **不得**用于任何符号结论。
2. **Figshare RW：$q$ 符号稳定（恒负），但幅度可变化 1.6 倍**
   （$-0.205\to-0.329$）。在 A–D 处理下 $\mathrm{CoC}_1$ 恒为 2.315
   —— 因为其**已观测**的 TDS=1378 / chloride=313 才是紧约束，
   缺测物种在本档位**不绑定**。
3. **⚠ 对 WP2/WP3 既有论断的修正**：WP2 §6 与 WP3 §2.1 称
   "Figshare RW $\mathrm{CoC}_1=1.000001$（触下限、退化）"。
   本轮实测：该值**仅在 `limit_scale=0.25` 出现**；而项目默认档
   `limit_scale=1.0` 下 Figshare RW 的 $\mathrm{CoC}_1=2.02$（$\varphi=0.6$），
   **并不退化**。故"触下限"这一排除理由**依赖于一个无实测支撑的外推档**
   （A26 §1 明确 `0.25` 为外推压力档）。排除 Figshare RW 的**正当理由应改为
   "组成不完整（缺 2 物种）+ 量级敏感"**，而非"触 CoC 下限"。
4. **Figshare BW：** $q=-0.851$、$dS=+1.27\times10^5$ ML（极有害），
   且对填充完全无响应（其已观测的高 TDS/chloride 主导）。但它是**苦咸水、非再生水**，
   必须**完全排除**在任何再生水组成统计之外。

## 4. 对主结论的影响（一句话）

> 在**完整物种**水样上，回用在全部 47 个可靠情景中均降低城市取水（$dS_{\rm pot}<0$），
> 但驱动因素是**再生水取用量 $x_{\rm AI}$**（$\mathrm{corr}(x_{\rm AI},dS)=-0.93$）
> 而非水质项（$\mathrm{corr}(q,dS)=-0.16$）——**$q$ 的符号在 IEUA/LADWP 间确实分化，
> 但它不与 $dS_{\rm pot}$ 同向，故不能作为"回用有益性"的机制解释**。
