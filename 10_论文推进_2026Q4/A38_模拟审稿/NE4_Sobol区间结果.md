## 0. ⚠️ 首轮失败与自救留痕（必须先读）

首版脚本产出 **ΣS1 = 1.298 > 1**（数学上不可能）与"`coc_design` ST=0.000 却标显著"的
自相矛盾结果。**根因是我自己的代码 bug，不是引擎问题**：

```python
yA = np.array([evaluate(...) or np.nan for ...])   # ❌
```

`evaluate()` 对合法的**零挤占**情景返回 `0.0`，而 `0.0` 在 Python 中是 **falsy**
⇒ **合法的 0 被静默转成 NaN**。实测 128 点中有 **54 个真实零点被误删**。

> **这与本项目既有门禁"缺失不得静默按 0 / 0 不得静默当作缺失"是**同一类错误的反向版本**。**
> 修正：显式区分 `None`（不可识别）与 `0.0`（合法零），用 `safe()` 包装。
> 修正后有效点由 33/128 恢复为 **128/128**，ΣS1 回到 0.188 / 0.581（均 ≤ 1）。

## 1. 方法

- **Saltelli 设计**：$N_{\rm base}=128$，$d=7$ 参数 ⇒ 每配置 2048 行；
- **估计器**：标准 Sobol $S_1$ / $S_T$；
- **区间**：对 Saltelli 样本做 **bootstrap 重采样（NB=400）**，取 2.5/97.5 百分位；
- **固定种子** `20261016`（可复现）；
- **显著判据**：$S_T$ 区间**下界 > 0**；
- 只用**完整物种**水样；`Figshare BW` 排除；失败/退化点标 `NOT_IDENTIFIABLE`，**不插补**。

## 3. 结论

### 3.1 支持 WP5 的定性结论（并获得区间）
- **`limit_scale` 是主导因子**（IEUA $S_T$=0.330；LADWP $S_T$=0.891，且 $S_1$=0.468 为最大主效应）
  ⇒ 与 WP5 的 `ST=0.944` 方向一致；
- **`x_alkalinity` 对 IEUA 显著**（$S_T$=0.125，CI [0.015, 0.305]，下界 > 0）
  **而对 LADWP 实质为零**（$S_T$=0.001）
  ⇒ **这从独立方法上印证了 NE-2 / WP5 的核心机理**：碱度只在**碱度受限的水样**上起作用，
  对碱度宽松的 LADWP 无影响。这是本项最有价值的交叉验证；
- `pool_scale` / `gap_scale` / `e_scale` 在两配置下均为**精确零** ⇒ 在本参数域内不驱动 $dS$。

### 3.2 必须诚实报告的限制
1. **ΣS₁ ≪ 1**（0.188 / 0.581）⇒ **主效应只解释约 19% / 58% 的方差**
   ⇒ 排名**不得**被读作"前两名就够了"；
2. **`phi` 的 $S_T$ 区间极宽**（[0.051, 2.568]）⇒ 其总效应**方向确定但量级不确定**，
   不宜在正文中给单点数值；
3. **`coc_design` 的 ST 区间下界为 0.000（IEUA）却标"显著"** ⇒ 这是判据在边界上的
   人为效应（下界恰为 0 与 0.001 之间），**不构成实质发现**，正文不应引用；
4. **$\Sigma S_T > 1$**（1.381 / 1.172）超出 1 的部分为估计器偏差与强交互，
   Saltelli 估计量在有限样本下允许此偏差，但应注明；
5. 仅 **1 个域（ha）× 2 水样**、$d=7$（原 12 维中省略 5 维并显式声明）。
