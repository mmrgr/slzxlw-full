## 1. 口径与门禁 (先声明, 后报数)

### 1.1 主估计量 (唯一口径, 不得混入 B0)

```
dS_pot = C - F = max(0, inc_B2 - inc_B1) - [ (M0 - M1) + x_ai ]
```

- `B1` = 有数据中心**不用**再生水 (`ai_target=0`) → `M0, inc_B1, CoC0`
- `B2` = 有数据中心**使用**再生水 (`ai_target=phi`) → `M1, inc_B2, CoC1, x_ai`
- 符号: `dS_pot > 0` ⇒ 城市净取水**上升** (有害); `< 0` ⇒ **下降** (有益)
- `max(0, ·)` 是物理必需: 池在 B1 被既有用户用尽时带符号位移恒等于 `-x_ai`,
  不截断会**双计** `x_ai` (A33/WP4 §(c)、A13/COLUMN_NAMES_CORRECTED.md 已评审口径)。

### 1.2 与既有产物的一致性核验 (全部实测, 不是声称)

| 检验 | 结果 |
|---|---|
| 锚点 `ha\|IEUA\|phi=0.6\|ps=1` 对 WP4 `wp4_results.csv` | WP5 `-7585.088416` vs WP4 `-7585.088415776312`, **相对差 0.000e+00** ✅ |
| A13 式 `F = M0 - (1-phi_eff)·M1` vs WP2/WP4 式 `F = (M0-M1) + x_ai` | n=15, **最大相对差 4.738e-16** → 两式**恒等** (`x_ai ≡ phi_eff·M1` 在 B2 支路按构造成立) |
| 体积口径 (WP5: `S_city = S_AI + inc_recl - pool`) vs 固定池口径 | 冻结基座处**恒等**; 差异只在 `pool`/`gap` 被外生改变时出现 |
| 缓存键自检 (M5 复发防护) | 共享 cache 下各水样 `CoC1` = `{IEUA: 3.153733, LADWP: 4.777245}` → 取值互异 ✅ 组成维度有效 |
| `dS = C - F` 定义自洽 (相对容差 1e-9) | 通过 |

> **WP5 与 WP4 的口径差异是刻意为之**: WP4 在"固定池"下扫描 (`pool=P0·pool_scale`),
> WP5 在"城市水量会计"口径下求解, 使 `dS_pot` 成为 `pool/gap/需求/化学/技术` 的显式函数 ——
> 否则敏感性分析没有控制量可扫。两者在冻结基座处逐位一致。

### 1.3 双门禁与有效样本数

① `B2` 支路 `status == "converged_unique"`; ② `B1` 支路单根且闭合
(`roots==1` 且 `|closure_residual| ≤ 1e-9`, `M0 > 0`); ③ 两支路 `CoC > 1.000001`。

这解释了 §2.2 中 `x_chloride` 的 `mu_star ≡ 0` 与 `x_TDS`/`x_silica` 的极小值。

### 2.5 未闭合与负结果 (如实报告)

- **`LADWP` 的 Sobol 指数 = `NOT_IDENTIFIABLE`** (ha 与 co 均然): Saltelli 设计内
  `7/512` 与 `6/512` 个点门禁失败 (B2 水质定常解不存在/不唯一)。引擎的 Sobol 对 NaN
  **静默传播** (`variance → NaN` → 全部指数 NaN), 故该两配置的指数**不可解释**。
  按纪律报 `NOT_IDENTIFIABLE`, **不插补、不蒙混**。
  Morris 不受影响 (它逐维成对比较, NaN 步已显式计数: `n_nan_effects = 1`)。
- `x_silica` / `x_hardness` / `x_chloride` 在现行 baseline 限值下**无可辨识影响** ——
  这是**负结果**, 不修饰。
- LADWP 下 `x_alkalinity` 退到第 7 位 (`mu_star = 129`): 其 `限值/浓度 = 49.3`
  远大于 IEUA 的 2.5, 碱度不再受限, 主导量变为 `phi`/`limit_scale`/`gap_scale`。

### 2.6 ⚠ 发现的自身缺陷 (已修, 必须披露)

首轮运行时 **4/4 配置的 Sobol 指数全为 NaN**。根因**不是**数据/引擎限制:

> `Evaluator._collect` / `chem_map` 对参数点**硬下标取键**, 而 Sobol 降维后参数点只含被抽样
> 的子集 → 每次都 `KeyError`; 旧 `raw()` 用裸 `except Exception` 把它吞成 NaN。

**危险性**: 这正是"用替代品蒙混"的反面 —— 代码缺陷被伪装成"情景不可辨识", 若不复核就会
输出"4/4 配置 NOT_IDENTIFIABLE"这一**假结论**。

**修复**: (i) 未抽样维回落冻结取值; (ii) `raw()` 只吞 `ValueError/ZeroDivisionError/OverflowError`
这类**引擎在不可行情景上抛错**的信号, `KeyError` 等**代码缺陷直接向上抛**;
(iii) `sobol_guarded` 把"门禁失败"与"引擎抛错"**分别计数**。
新增断言 (`_probe9`) 验证: 故意抛 `KeyError` 的评估器必须向上传播 → **PASS**。

### 2.7 Morris 实现说明 (引擎实现被替换)

引擎 `aiuwm.sensitivity.morris_sensitivity` 按 `min(high, base+Δ)` / `max(low, base-Δ)` 取点:
当 `base+Δ` 恰落在 `high` 时, 实际步长可能远小于 `Δ`, 但效应仍除以 `Δ/(high-low)`,
会**系统性放大**效应; 且它不检测 `actual_delta == 0`。
本脚本改用**教科书 Morris 轨迹** (归一化 [0,1]^k 上 8 级网格, 固定网格步长
`Δ = p/(2(p-1)) = 0.5714`, 一次只动一维), 并显式统计 `n_zero_delta`。
**Sobol 未改动**, 直接复用引擎实现。

### 3.4 人为扰动下的翻转临界点

| 域 | 水样 | 热浪翻转 `e_scale` | 干旱翻转 `avail_frac` |
|---|---|---:|---:|
| ha | IEUA | **6.75** | 无 (扫至 0.001) |
| ha | LADWP | 无 (扫至 40×) | 无 (扫至 0.001) |
| co | IEUA | **6.75** | 无 (扫至 0.001) |
| co | LADWP | 无 (扫至 40×) | 无 (扫至 0.001) |

**⚠ 机制澄清 (否则会被误读为"热浪越大越有害")**:
`dS_pot = C - F`, 其中 `F = (M0-M1) + x_ai = M0 - (1-phi_eff)·M1`。
极端 `e_scale` 下 `M0`、`M1` 同比例放大, 而 `phi_eff` 被可得再生水量钉住 → **`F` 变负**,
即"再生水顶掉的自来水多于它自身取用量"(净替代为负)。

**闭式条件**: `F < 0 ⟺ phi_eff < 1 - M0/M1` —— 实测核对 **20/20 命中 ✅**。
故该 `+` 号翻转**不是"城市受害"**, 而是 `F` 变负的会计后果: 城市净取水比 `B1` 更低,
账面上**仍属受益方向**。

**外推警告**: `e_scale > 10` 后 `CoC1` 钉在水质下限 `2.8226` (碱度受限), `phi_eff` 恒定,
`M1` 随 `e_scale` 线性增长 —— 该区段是**引擎线性外推, 无观测支撑**, 仅用于定位临界点,
**不用于结论**。

**干旱负结果**: `avail_frac` 从 1.0 扫到 0.001 仍**未**翻转 (4/4 情景), `dS_pot` 单调趋近 0 但不改号。

### 3.5 谁受益 / 谁受损; 数据中心是否受限

- **谁受益**: 全部 64 个可靠情景 (含全部极端窗) 的 `dS_pot < 0` ⇒ **城市净取水下降, 城市受益**。
  机理: 每个情景的带符号位移 `inc_B2 - inc_B1 = -x_ai` (池在 B1 被既有用户用尽) ⇒ `C = max(0,·) = 0`;
  既有用户**未被净挤占**, 而是 AI 引入的再生水替代了自来水 ⇒ `F > 0` 而 `dS = -F < 0`。
- **既有用户 vs 数据中心**: 既有用户在 B1 已用尽池 (`inc_B1 = pool`), 在 B2 让出 `x_ai`
  **但由 potable 补回** (引擎的联合求解语义), 故其交付量不下降; 受损方**没有出现**在可靠子集内。
- **数据中心运行是否受限**: **观测热浪不构成运行受限** —— 蒸发式下 PUE 仅 1.1805→1.2347,
  E/day 1.095×, 需求与供水同步上升。**受限需由供给缩减或水化学恶化触发**:
  供给限流下引擎 fixed-point 解显示 AI 再生水占比由 `avail=1.0` 的 0.6000 单调降到
  `avail=0.1` 的 **0.0775 (ha) / 0.0720 (co)**, `CoC` 由 2.8226 升到 3.3947 ——
  AI 取水量下降但**仍 > 0**, 即**未被完全切断** (`status=converged` 全程)。

## 4. ★ 不确定性分解 (参数 / 结构 / 情景 —— 分开报告, 不混为单一误差条)

### 4.1 参数不确定性

连续参数在边界内变动 (条件于给定 域×水样×结构)。主配置门禁失败率 **0.24–0.50%**, 已剔除。

- **Morris 前 3**: `limit_scale` (45 062) > `x_alkalinity` (24 841) > `phi` (14 489) [ML]
- **Sobol 前 3**: `limit_scale` (ST=0.944) > `x_alkalinity` (ST=0.682) > `pool_scale` (ST=0.251)
- **符号层面**: 只有 `x_alkalinity` 能翻转符号 (§2.4)。

⚠ `limit_scale` 与 `x_alkalinity` 在机制上**不可分离**: 二者都只通过"碱度受限的 CoC"起作用
(`CoC_lim ∝ limit_scale`, `conc ∝ x_alkalinity·140`)。它们的 `ST` 是**同一机制的两个入口**,
不应被读作两个独立的物理杠杆。

### 4.2 结构不确定性 (离散口径选择, 不是连续参数)

| 结构维度 | 对照 | 结果 |
|---|---|---|
| **面板** | `A_engine2` (2 物种 TDS/Cl) vs `B_full` (5 物种) | `ha\|IEUA` Δ=+510.94 (**6.74%**); `ha\|LADWP` Δ=−2 835.67 (**25.9%**); `co\|IEUA` 6.83%; `co\|LADWP` 26.4%。**符号 4/4 均不翻转** |
| **F 式** | WP2/WP4 式 vs A13 式 | n=15, 最大相对差 **4.738e-16** → **恒等** |
| **体积口径** | WP5 会计口径 vs WP4 固定池口径 | 冻结基座处**恒等** (相对差 0.000e+00) |

`A_engine2` 的机理值得单列: 它只有 `{TDS 2200, Cl 500}`, 实测 `CoC1` 在 4/4 情景全都
**钉在设计上限 5.0** ⇒ 该面板下**水质约束完全不起作用**, `dS` 退化为与组成无关的常数
`-8096.03` (ha) / `-7187.03` (co)。这正是 LADWP 上 26% 差异的来源 ——
不是"A_engine2 更准", 而是**它丢掉了唯一受限的物种 (碱度) 后约束失效**。

**读法**: 结构不确定性对 `|dS_pot|` 的影响可达 **26%** (LADWP 下换面板), **远大于**情景间差异;
但对**符号**无影响。且这 26% 是**模型规格错误**造成的, 不是真实的物理不确定性 ——
按 `A27` 的裁定, 主口径必须用 `B_full` (5 物种引用档), `A_engine2` 仅作对照。

### 4.3 情景不确定性 (水样 × 域)

40 个压力域均匀参数点 (seed `20261016`) × 4 情景 = 160 点, **门禁失败 0** (`n_eff=160`)。
确定性 ANOVA 分解:

| 分量 | SS | 占比 |
|---|---:|---:|
| 情景**间** (水样×域) | 5.865e9 | **3.85%** |
| 情景**内** (即参数) | 1.465e11 | **96.15%** |

组均值 (ML): `ha|LADWP` −15 008 (sd 10 962, 40/40 全负) > `co|LADWP` −13 787 (40/40 全负) >
`ha|IEUA` −2 403 (36 负 / 4 正) ≈ `co|IEUA` −2 237 (36 负 / 4 正)。

**⇒ 裁定: 参数方差主导 (96.2%), 情景(水样×域)间不主导 (3.8%)。**

**⚠ 这条结论必须加限定, 否则会与 §4.2 冲突**:
- 在**冻结参数点**上 (§3.3, `phi=0.6, ps=gs=1, ...`), 换水样使 `|dS|` 从 7 585 → 10 932 ML (ha),
  即 **+44%**; 换域 (ha→co) 只使 `|dS|` 从 7 585 → 6 728 ML, 即 **−11%**。
- 而在**压力域**抽样下, 组间方差只占 3.85%。原因: `IEUA` 组被推到了 `+2.4e5 ML` 的正值尾部,
  其 sd = 4.4e4 是 `LADWP` 组 (sd ≈ 1.0e4) 的 **4.3 倍** —— 组**内**方差被外推点撑大。

两者不冲突, 而是说明**方差占比依赖于抽样域**:
> **在冻结/近冻结域, 水样 (情景) 是主导的 (44%); 一旦向压力域外推, 参数方差淹没情景方差。**

因此本报告的**分层结论**是:
> **可观测风险层面, 水样的组成差异主导, 且当前只在 `alkalinity` 一个物种上起作用 (44%);
> 参数外推的方差更大 (96%), 但那是模型外推, 不是可观测风险。**

### 4.4 三类不确定性汇总 (不合并)

| 类型 | 量级 (对 `dS_pot`) | 是否影响符号 |
|---|---|---|
| **参数** | Morris `mu_star` 高至 4.5e4 ML; Sobol `ST` 高至 0.944 | 仅 `x_alkalinity` (临界 2.62×) |
| **结构** | 换面板改变 `|dS|` 达 **26%** | 否 (4/4 不翻转) |
| **情景** | 冻结点换水样改变 `|dS|` **44%**; 压力域组间方差占比 3.85% | 否 (观测窗 8/8 不翻转) |
| **极端事件 (观测驱动)** | 最大 **1.139×** 量级偏离 | **否** (8/8 不翻转) |
