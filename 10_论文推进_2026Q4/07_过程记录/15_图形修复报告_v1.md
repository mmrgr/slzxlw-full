### F-3 `A6_可信度配图/make_fig2.py`（SI Fig.S2）

**根因**：脚本按 **T6 v1** 的列名读 `T6_coc_limits.csv`，而该文件已在 **11:19** 被 **T6 v2** 覆写 →
自那时起 `AttributeError: 'Series' object has no attribute 'f_star'`，成品图停在 **02:00**（v2 之前）。

| 面板 | 位置 | old（v1 列名） | new（v2 列名） |
|---|---|---|---|
| A | f* 标记 | `r.f_star` / `r.source` | `r.f_star_2ind` / `r["sample"]` |
| B | 排序键 | `coc.sort_values("chi_full")` | `coc.sort_values("chi_eff_all_ratio")` |
| B | 全组分条 | `o.chi_full`，legend `"full panel"` | `o.chi_eff_all_ratio`，legend `"all species (composition ratios)"` |
| B | 仅 TDS/Cl 条 | `o.chi_2indicator` | `o.chi_eff_conservative`（v2 的 conservative 判据集 = TDS/Cl，因 `LIMIT_SETS` 无 SO4 键，等价于"仅 TDS/Cl"） |
| B | 物种标注 | `r.limiting_species_full` | `r.who_all` |
| B | y 轴标签 | `o.source` | `o["sample"]` |
| C | 标题 | `"C  Central relation confirmed by measurement (MAE 0.0018)"` | `"C  Source-report water balance is arithmetically self-consistent (MAE 0.0018); not an independent test"` |
| C | 图例 | `"GSA courthouse tower, measured"` | `"GSA courthouse tower, as reported"` |
| C | 模型点 | `([5.0], [1.225])`，label `"AI-UWM (design)"` | `([5.0], [1.25])` + 新增有效点 `([5.444], [1.2249])` | 
| D | 口径 | `0.190 / 1.821 L/kWh`（分子分母口径不同） | 读 `T7_summary.json` 的 `0.183 / 1.401 L/kWh`（**同为园区口径**，标 `7.6×`） |

**连带修正的理由（`14` §6.3 明确要求）**：
- **C 标题**：GSA 主张已在审计 C5 / 一致性核验 Q14 降级为"**源报告水量账算术自洽**"
  （给定 CoC 时 `CoC=M/(M−E)` 是代数恒等式），旧标题"独立验证"属**已作废主张**。
- **C 模型点**：旧版把模型标在 `(5.0, 1.225)`，但 `1.225` 实际对应**有效 CoC = 5.444**（口径差 8.16%），
  该点**不在**恒等曲线上；现分列"设计点 (5, 1.25)" 与"有效点 (5.444, 1.2249)"，两点都落在曲线上。
- **D 口径**：旧版拿 **冷却/IT 口径**的 1.821 去比 **园区口径**的 0.190（隐含已撤回的 **9.6×**）；
  现改为**园区对园区**（1.401 vs 0.183 = **7.6×**），数值全部取自 `T7_summary.json` 的 `meta_disclosure`，
  直方图亦只画**有效披露行**（`excluded == False`，n = 70），与 T7 的 90→70 剔除口径一致。
- **单位与标签**：面板 D 的 y 轴成为"facility-years"，x 轴改标 `log₁₀ park WUE`。

> **未改**：面板 A 的 CoC_lim(φ) 物理曲线、面板 B/C 的散点坐标来源、配色、dpi、画布尺寸。

### F-4 `A7_质量分配联合/make_fig5.py`（**主图 Fig.4**）

**根因**：面板 b 按**审计 B4 之前**的 `T2_cell_results.csv` 读 L 维（`Ld` / `Ls` 两个字符串），
而 B4 修正后 L 已拆为 **2×2 全因子**（`Ld_claimP0_capP0` / `Ls_claim0_capGap` /
`L_claim0_capP0` / `L_claimP0_capGap`）→ 自 **11:20** 起 `KeyError: ('Q0', 'Ld_claimP0_capP0')`，
成品图停在 **02:10**（B4 之前）。

| 位置 | old | new |
|---|---|---|
| 面板 b 的 `style` 字典键 | `("Q0","Ld")` / `("Q0","Ls")` / `("Q1","Ld")` / `("Q1","Ls")` | `("Q0","Ld_claimP0_capP0")` / `("Q0","Ls_claim0_capGap")` / `("Q1","Ld_claimP0_capP0")` / `("Q1","Ls_claim0_capGap")` |
| 面板 b 过滤 | 无（直接 groupby） | `sub = sub[sub.L.isin(L_ENDPOINTS)]`，其中 `L_ENDPOINTS = {"Ld_claimP0_capP0": "$L_d$", "Ls_claim0_capGap": "$L_s$"}` |
| 面板 b legend | `f"{q}-{l}"`（会显示 `Q0-Ld_claimP0_capP0`） | `f"{q}-{L_ENDPOINTS[l]}"`（显示 `Q0-$L_d$`，与原图一致） |

**为什么取这两个端点**：T2 脚本 docstring 明确写"**并保留原 Ld / Ls 作为两个选定端点**：
`Ld = (claim=P0, cap=P0)`；`Ls = (claim=0, cap=gap)`"。故本面板仍是原来的
**Q0/Q1 × $L_d$/$L_s$ 四线**（"four allocation-quality regimes"），语义未变、只是取回了正确标签。

> **未改**：面板 a（CoC(φ) 曲线）、面板 c（交互项条形）、面板 d（再循环累积）以及全部配色/画布。
