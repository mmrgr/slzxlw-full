## 三、必须纠正的一个口径错误（比数字本身更重要）

### 3.1 6% / 26% 不是本文的 r

| 量 | 定义 | 分母 |
|---|---|---|
| **市府图的 26%** | 数据中心再生水用量 ÷ **全市再生水总用量** | 全市 |
| **本文的 r** | 园区补水中的再生水量 ÷ **园区总补水量** | 园区 |

**两者完全不同。** 把 26% 直接当作 r = 0.26 是**错误**的。

### 3.2 但两者可以换算

设：
- `P` = 全市自来水总用量
- `R` = 全市再生水总用量
- 数据中心用自来水 `= 0.06P`，用再生水 `= 0.26R`
- 园区补水 `D = 0.06P + 0.26R`

则园区替代率：

```
r = 0.26R / (0.06P + 0.26R) = 1 / (1 + (6/26)·k)     其中 k = P/R
```

### 3.3 由此得到的关键数字：k\* = 3.50

**当全市自来水总量是再生水总量的 3.50 倍时，园区 r 恰好等于 r\* = 0.5532。**

| k = P/R | r（园区替代率） | 相对 r\* = 0.5532 |
|---:|---:|---|
| 1.0 | 0.8125 | 远高于（已在反噬区） |
| 2.0 | 0.6842 | 高于 |
| **3.0** | **0.5909** | **略高于** |
| **3.5** | **0.5532** | **恰好相等（临界）** |
| 4.0 | 0.5200 | 略低 |
| 5.0 | 0.4643 | 低于 |
| 10.0 | 0.3023 | 远低于 |

**k\* = 3.50 是判断 Santa Clara 的数据中心是否已进入"水质反噬区"的分水岭。**

### 3.4 现实判读

Santa Clara 是**重度回用城市**（33 英里再生水管网，供水与再生水双系统）。这类城市的 `k = P/R` 通常较低（再生水占比高）。

- 若 `k ≈ 3`（再生水量达自来水的 1/3）→ `r ≈ 0.591`，**已略超 r\***
- 若 `k ≈ 5`（再生水量为自来水的 1/5）→ `r ≈ 0.464`，**未超**

→ **Santa Clara 恰好落在本文判据的临界域。** 这是本文 `r*` 判据第一次有真实城市的临界性。
