# 预注册补丁 #2 —— 指标 B/C 解锁与时间尺度口径

**日期**：2026-10-14
**触发**：审计 `05_方法审计_v1.md` §B5（单日代表 + 年度缩放）与 §D4（指标 B/C 未做）
**性质**：本补丁在 **T5/T14 任何新结果产生之前**写下，用于固定时间尺度口径与指标 B/C 的定义，
并解除补丁 #1 中 L3 对 B/C 的全面封禁。

---

## 1. 时间尺度口径（冻结）

1. **主结果时间步 = 1 天**。逐日驱动 = `examples/cawcc_r2/{ha,co}/timeseries.csv`（730 天）。
2. AI 计划**必须**按 `load_mode="timeseries"` 逐日调用 `calculate_data_center_plan`，不得再用"中位日比值 × 年度总量"。
3. **年缩放合法性**：仅当 $M/E$ 逐日为常数时，年度缩放才与逐日求和等价。该条件**必须在每次运行中校验并报告**
   （T5 已实现：蒸发式 min = 中位 = max = 1.225025，ΣE 与冻结 `E_total` 相对差 < 1e−15）。
4. **小时尺度不在本轮范围**；指标 C 的表述一律限定为"日尺度高峰"。

## 2. 热浪窗与应力轴（冻结）

- 热浪窗：湿球 ≥ 该域 730 天湿球分布的 **p95**（ha ≥ 25.36 °C，co ≥ 17.78 °C，各 37 天）。
- 全湿阈值：引擎 `hybrid_full_wet_bulb_c` 默认 **24 °C**（ha 70 天，co 0 天）。
- 应力轴：$\tau(t)=\dfrac{M(t)/\bar M}{Q(t)/\bar Q}$，$Q$ = 流域来水。
- 对照窗：按湿球排序取与热浪窗等量的**最低**湿球日（"匹配非热浪窗"）。

## 3. 指标 C 定义（冻结）

| 量 | 定义 |
|---|---|
| 替代覆盖率 | $\mathrm{cov}(t)=\min\!\big(\sigma R(t),\,0.7\,M(t)\big)\big/\big(0.7\,M(t)\big)$ |
| 失效 | 当日 $\sigma R(t) < 0.7\,M(t)$ |
| **峰值失效临界规模** | $s^\ast(\sigma)=\min\{s: \max_t\,[\,0.7\,s\,M(t)-\sigma R(t)\,]>0\}$ |
| 报告格式 | 覆盖率与失效概率**必须**同时给出"热浪窗 / 非热浪窗 / 全程"三列 |

其中 $\sigma$ = AI 可用的再生水池份额（**政策参数**，本轮取值 0.30/0.50/0.70/1.00）；
$R(t)$ = 整链引擎逐日 `reuse_delivered_ml`；$M(t)$ = 逐日总外部补水。

## 4. 指标 B 定义（冻结，仅作扩展分析）

- 流域取水 = 补水 × (1 − 再生水占比)；回流 = `return_flow` × (1 − 再生水占比)（**严格来源归属**）；
  净耗水 = 取水 − 回流。因此所得差值为**上界**估计，必须标注。
- **前置条件**：指标 B 仅在具备**经校验的流域水文模型**时可用于实质结论。
  本研究的来水为合成代理，故 B **一律标注为"量级扩展"，不得与指标 A 合并**。

## 6. S_city 跨时间尺度的一致性纪律（冻结）

- 窗口/分组的 $S_{\rm city}$ **必须复用冻结模块 `city_model.solve_city`**，仅允许替换其时间尺度参数
  （`E_total`、代表日、池、缺口）。**禁止**自建单时间步分配器用于结论。
- 已知反例（本轮实测）：自建"单日城市解"与冻结年度模块的分配器语义不一致
  （日尺度：既有用户得 0、竞争池未被用尽；年度：37:63 且池用尽）。该实现**记为诊断件，不得进入结论**。
- 一致性自检：全年窗口的 $S_{\rm city}$ 必须与冻结值吻合（ha/蒸发式 = −837.1 ML/730 d）。
