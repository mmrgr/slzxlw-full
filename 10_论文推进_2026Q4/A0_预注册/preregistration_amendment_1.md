## 1. 作废项

原 `04_阶段结果_T9.md` §5 声明的 Gate：

```
max|Δy| < 1e-6   且   未折叠散度 > 3 × 折叠散度
```

**本判据作废**，原因：

1. 原预注册 `preregistration.md` §6 只写了 `F3 = 无量纲折叠散度不收敛`，**未定义"散度"、未给阈值**；
2. `1e-6` 与 `3×` 两个数在预注册文件与 v2 规划中均不存在，系看到 T9 数据后设定（HARKing）；
3. 更根本地，T9 的折叠式 `y = Φ(w−u)` 经审计确认为**代数恒等式**——

   ```
   δ := 1 − (pool − inc_recl)/x_ai
   ⟹  Φ·(w−u) ≡ [m₀ − M + x_ai + inc_recl − pool]/m₀ ≡ S_city/m₀
   ```

   即残差 ~1e-15 与 R²=1 **由 δ 的定义保证**，与物理、引擎、抽样无关。
   因此它不能作为任何"成立/不成立"的判据。

**T9 的折叠结论**降级为：一次**代数化简（reparameterization）**，其价值仅限于
"证明引擎三个模块未引入第三个状态变量"。**不具备可迁移性含义。**

## 2. 新预注册判据（Gate G-B′）

可迁移性的正确检验是：**分配结果 δ 能否由外生参数预测**。
在 T9b 运行前，预先冻结如下判据。

- **被检量**：`δ = 1 − (pool − inc_recl)/x_ai`（与 T9 同一定义）
- **外生预测式**（零拟合，事先固定，不调参）：

  ```
  δ_pred = clip( ΔP / max(P + ΔP − min(G, P), ε), 0, 1 )
  ```

  其中 `P` = 再生水池规模、`G` = 既有用户未满足的可回用需求、`ΔP` = 新增回用产能。
  语义：既有用户先补缺口，AI 只从"缺口之外的新增供给"中取水。

- **通过条件**：
  - `R² ≥ 0.90` 且 `中位相对误差 ≤ 20%`（对全部 480 情景）
- **失败条件（事先声明）**：不满足上述条件
  - ⟹ 判定 **折叠坐标不具跨城市可迁移性**
  - ⟹ 论文主张降级为：**"条件机制 + 描述性坐标"**，不得声称"可迁移规律"
  - ⟹ 必须显式写出模拟参数域（2 个同源合成城区、LHS 采样区间），不得外推

- **附加报告（不作为通过条件）**：
  - `sign(y)` 判别准确率 —— 论文实际关心"城市是否净收益"
  - δ 落在物理域 [0,1] 之外的比例 —— 提示 δ 定义的稳定性
