## 二、核心科学进展

### 2.1 统一恒等式（取代单口径结论）

$$dS_{\rm pot}=C-F=\underbrace{(r_{\rm inc}^{B_2}-r_{\rm inc}^{B_1})}_{\text{挤占位移}}-\underbrace{(M_0-M_1)}_{\text{水质惩罚}}-\underbrace{x_{\rm AI}}_{\text{AI 取用}}$$

**残差 5.8e−11（1 152 情景）**。两分支：
- **纯挤占** → 退化为 $dS=M_1-M_0$（**旧结论被定位为其中一支，而非被推翻**）
- **无挤占** → $dS=-(M_0-M_1)-x_{\rm AI}$

**符号判据**（吻合率 **1.000**）：$dS<0 \iff x_{\rm AI}+(M_0-M_1)>C_{\rm disp}$

### 2.2 E2 三分账与四结局（完整日尺度引擎）

| 发现 | 实测 |
|---|---|
| 需求/交付/取水三者相等情景数 | **0 / 68** |
| 路径效率 $\eta_{\rm path}$ | 0.849（边际楔 1.178） |
| **虚构取水**（报告了取不到的水） | 最多 **6 713 ML** |
| 四种结局 | 保持 / 转必要服务缺口（最大 **62 080 ML**）/ 符号反转 / **数据中心自身被削减**（最大 **8 519 ML**） |
| 命题 H1–H4 | 两域**零否证** |

### 2.3 新的结构性发现

1. **非单调可行域**：网格细化后 **11/39** 曲线呈"失效—恢复—再失效"（修复前 0/39 不可见）→ **粗网格会漏掉真实可行窗口**。
2. **零竞争下也能抬高城市取水**：C 态 **17/446** 为正值，判据 $M_1-M_0>x_{\rm AI}$ 以 **100%** 吻合率复现 → **水质惩罚是独立的、可反向的力**，不是置换的修正项。
3. **组成能翻转符号**：高盐再生水 **+28 437 ML**（害）vs RO 产水 **−3 904 ML**（利）。
4. **水质是"开关"**：真不约束时（`limit_scale=1e6`）A 态 $dS=$ **0.000000 精确**。

## 三、两处实质缺陷（自查发现，均已修复）

`city_model.make_evaluators` 的缓存键不含 `q` → 共享 cache 时**第一个水样的结果被复用给所有水样**。

| | 修复前 | 修复后 |
|---|---|---|
| 3 水样 CoC | 全为 2.3165 | 2.3165 / 3.0984 / 1.7831 |
| 组成有效变异占比 | **0%** | **100%** |
| $dS_{\rm pot}$ 范围 | 0 … +29 103 | **−51 876 … +116 581** |
| 负值（城市取水下降） | 0 个 | **121 个** |

### 缺陷 2：桥接 harness 用错基准量（中等）
逐日臂用**补水 M** 当**蒸发 E** → $M_0$ 虚高 1.60×。
修复后 **$M_0$ 在 24/24 配对中逐位相同**（中位与最大相对差均 **0.000000**）→
**冷却物理口径等价性得证**；残余分歧归因到"组成分辨率"（IEUA 12/12 符号一致，LADWP 8/12）。

> **共同教训**：两者都是**静默错误**——程序不报错、数值收敛、单位一致，
> 但**变化维度被抹掉**或**基准量被替换**。

## 六、新增门禁（可复现，勿删）

1. **维度有效性检验**：任何声称"扫描"的因子必须**实测产生变异**。
2. **跨模型基准断言**：任何跨模型对照必须断言**共享量数值一致**。
3. **缓存键完备性**：缓存键必须含**所有影响结果的输入**。

> 若早做第 1 项，缺陷 1 会在第一轮暴露；若早做第 2 项，缺陷 2 会立即暴露。

## 七之二、★ 本轮新增：动态状态实验（GPT §WP1.3，此前从未触及）

| 项 | 结果 |
|---|---|
| 水量闭合 | **9.77e−15 ML**（两路径均精确） |
| **CoC**：volume-only 在 φ=0.6 | **1.824** |
| **CoC**：R10a 在 φ=0.6 | **7.986**（≈设计值 8） |

- 主口径保持 volume-only（**保守界**），R10a 作为**结构敏感性**报告
  （引擎自身 R10 门禁标注该路径 `NOT_READY_FOR_E3`）。

**未发现超出守恒的新机制** —— 如实报告，不构造叙事。
