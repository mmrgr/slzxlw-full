## 2. 发现并修复的三个投稿版缺陷

### 2.1 标题后残留"内部版本说明"（**最严重**）

主稿标题正下方原本是：

```markdown
**Working draft v4 (2026-10-16).** Supersedes v3.
v4 changes are **substantive and include withdrawals**; see `A30_WP0取证/` ...
v2's "discharge–claim balance in a fixed pool" is **not withdrawn but subsumed** ...
Audit trail: `A13_可靠性机制/AUDIT_2026-10-14_撤回声明.md`, `18_方法自审与修复报告_2026-10-14.md`, ...
```

**这是审稿人打开稿件第一眼看到的东西**，且：
- "Working draft / Supersedes v3" 是内部版本管理，投稿版不该有；
- 引用 v2/v3 版本历史会让审稿人困惑；
- 一整段中文路径的审计线索应进 SI 或内部文档。

**处置**：移入 `A45_工程治理规划/_投稿版移出的版本说明.md`（保留留痕），
投稿版头部现在只有：**标题 → `---` → Abstract**。

> 撤回与更正信息**没有丢失**——它们本就在正文的 Correction/Retraction 注与 SI S10 中。

### 2.2 Declarations 中的中文待填提示

原为：
```
**⚠️ 需作者确认**（若确无，保留下述标准表述）
**⚠️ 需作者填写（不得代拟）**
**⚠️ 需作者填写**（基金号、数据提供者致谢等）
```

**矛盾**：直接删 → 丢失"待填"警示，作者可能漏填 10 个占位符；保留 → 英文投稿版出现中文。

**处置**：改为**英文 HTML 注释**，投稿系统不可见、作者源码可见：
```html
<!-- AUTHOR ACTION: fill in the author list and CRediT contributions, then delete this comment. -->
```

### 2.4 中文路径的处理原则
正文中剩余的中文都是**真实目录名**（如 `A30_WP0取证/`、`A32_WP3_水化学/`）。

**保留而非翻译**——理由：读者要按路径去归档里找文件，翻译路径就找不到了。
投稿时可整体替换为 Zenodo DOI 或补充材料编号（已在 Code Availability 中说明）。
