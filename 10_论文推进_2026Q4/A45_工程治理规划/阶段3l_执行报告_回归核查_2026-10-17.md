## 4. 加强第 12 道门禁（形式一致性）

原来的"参考文献格式与对应"检查其实很弱：
```python
dangling = {x for x in inline & ref_surnames if x not in body}  # 永远为空
```
这个表达式**恒为空**（`inline` 是从 `body` 里提取的，必然都在 `body` 里）——
**典型的形式主义检查**。

已改为真正有意义的检查：
```python
orphans = [s for s in sorted(ref_surnames) if s not in body]
if orphans:
    bad.append(f"文献表孤儿(正文未引用): {orphans}")
```

```
结果: ["文献表孤儿(正文未引用): ['Ghost']"]
```
✅ 有效。
