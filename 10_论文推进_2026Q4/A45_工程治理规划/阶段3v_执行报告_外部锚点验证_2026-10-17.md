### 2.1 但 `17 of 61` 的**表述**是错的

论文/SI 原文：
> Only **17 of 61 cities** (27.9%) have an industrial tariff above the reclaimed-water cost

**实测数据结构**：

| 项 | 实际 |
|---|---|
| 表行数 | **61** |
| **唯一城市数** | **31** |
| 说明 | 每城有 2 条记录（对应不同的源表列 `col`） |

⇒ **61 是"城市×源表列"的观测数，不是城市数。**

已改为：

**这是一个真实的精度缺陷**：审稿人会问"31 个城市怎么有 61 个观测"。

## 3. ★ 发现一个恒真的"假检查"

修表述时，我查到 `A37_六主图_v4/_gate_check.py` 里有一项：

```python
("WP10 17/61 = 27.9%", abs(17 / 61 * 100 - 27.87) < 0.01, f"{17/61*100:.1f}%"),
```

### 3.1 问题
**这是一个纯算术恒等式**：`17/61*100 ≈ 27.868`，与 `27.87` 差 0.002 < 0.01。
**它不读任何数据文件**，永远为真。

无论产物怎么变，这项检查都 PASS。

### 3.2 修复
改为从逐城 tariff 表**实时重算**：
```python
("WP10 17/61 = 27.9%",
 (lambda _d: (int((_d["median"] > 2.4125).sum()), len(_d)))(
     pd.read_csv(Path(__file__).parent / ".." / "A39_WP8_外部效度"
                 / "wp10_industrial_tariff_by_city.csv"))
 == (17, 61),
 "从 tariff 表重算"),
```

### 3.3 已验证会失败
把前 5 行的 `median` 改成 9.99（使 above 行数由 17 变 22）：

```
FAIL  WP10 17/61 = 27.9%   从 tariff 表重算
GATE FAILED (1): value mismatch
exit=1
```
