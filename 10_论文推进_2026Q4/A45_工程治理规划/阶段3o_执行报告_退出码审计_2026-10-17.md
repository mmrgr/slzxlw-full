## 1. 本轮发现第 3 个"退出码说谎"问题

上一轮修了 `required_statements.py` 的 `sys.exit(0)`。
本轮做**系统性审计**，立刻又抓到一个：

### `make_reproducibility_manifest.py` 完全没有退出码

```python
    rec(f"总状态: {status}")
    # ← 文件到此结束，没有任何 return / sys.exit


if __name__ == "__main__":
    main()   # ← 返回值被丢弃
```

`status` 会是 `ALL_CHECKS_PASS` 或 `HAS_FAILURES`，但**进程永远返回 0**。

### 1.1 为什么之前没被发现
`run_all_gates.py` 判定用的是**匹配输出文本**（`r"ALL_CHECKS_PASS"`），
所以功能"看起来正常"。但**任何按退出码判断的 CI 都会把失败当成功**。

### 1.2 修复与验证
```python
    return 0 if status == "ALL_CHECKS_PASS" else 1
...
if __name__ == "__main__":
    import sys as _sys
    _sys.exit(main())
```

**动态验证**（篡改 `wp2_e3b_combined_prediction_summary.json` 的逐折增益
使中位增益由 +0.092 变 0.000）：

| | 修复前 | 修复后 |
|---|---|---|
| 篡改后 exit | 0 ❌ | **1** ✅ |
| 输出 | ALL_CHECKS_PASS（误） | `[FAIL] E3b 折外中位增益=0.0000` + `HAS_FAILURES` |

产物已还原（逐折增益 0/0.2245/0.1837/0，oos_gain 0.1020，与记录一致）。

## 2. 新建退出码审计工具

| 判定 | 含义 |
|---|---|
| PASS | 有按结果的非零退出 |
