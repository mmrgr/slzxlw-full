SUBJECT: ★核心机制：有限供水可靠性闭合下的 S_city 符号反转临界条件
★核心任务：把现有"条件性守恒恒等式"升级为可证伪的机制发现。

【问题诊断（Lead 已确认）】
现有主稿中心结论 S_city ≤ 0 是模型闭合的代数产物，不是发现。证明（见 A10_敏感性与边界/city_model.py:259-261）：
  S_AI = (M0 - M) + x_ai
  S_city = S_AI + inc_recl - pool
在"再生水供给池固定(pool 外生) + 既有用户未满足需求由无限自来水回补"两条假设下，
inc_recl - pool ≤ 0 恒成立（分配是固定池的 pro-rata，见 reclaimed_allocation.py:349-369 map_allocation），
故 S_city ≤ S_AI 且在 pool 被占满时 S_city ≤ 0。这是一条守恒恒等式。
审稿人两行即可写出，GPT 提议的"重定位叙事"无法修复这一点。

【本任务要做的科学突破】
引入**有限供水可靠性闭合**：令城市自来水水源为有限资源（水库/流域），既有用户的需求弹性有限，
当 AI 挤占再生水时，被挤占的既有用户转回自来水，而自来水供给受"可用水量 + 可靠性约束"限制。
这样 S_city 不再恒 ≤0，而出现**符号反转**，反转位置由可测外生量决定。

必须完成：
1. 在 A13_可靠性机制/ 下新建 reliability_model.py，复用 A10/city_model.py 的真实模块调用路径
   （calculate_data_center_plan + solve_joint_quality_allocation，禁止重写规则）。
2. 引入可靠性闭合状态量并给出解析形式，至少包含：
   - W_pot：城市自来水可用量（外生，含干旱/热浪时段的时变序列）
   - 既有用户刚性需求 D_inc 与其可让渡份额（需求弹性 epsilon）
   - AI 挤占转回自来水的量 ΔD = f·M 或 δ 相关形式
3. 推导 S_city 在有限水源下的新表达式，并给出**符号反转的临界条件**（闭式，如 W_pot 低于某阈值、
   或弹性 epsilon 超过某阈值时 S_city 由负转正/由正转负）。要写成可证伪的命题 H_new。
4. 数值验证：在 (W_pot, epsilon, f, chi) 空间跑格点扫描，找出符号反转面；
   必须报告反转面是否存在、是否光滑、是否跨 ha/co 两域一致。
5. 消融：关闭可靠性闭合 → 必须退化回 S_city ≤ 0（用来证明新机制确实来自新增的物理，而非参数）。
6. 反例搜索：主动寻找使 S_city > 0 且不依赖新增产能的反例情景。
